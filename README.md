# TrueClicks Claude Plugins

Claude plugins for PPC account management by [TrueClicks](https://www.trueclicks.com). They work in Claude Cowork, the Code tab of the Claude desktop app, and Claude Code in the terminal.

## Available Plugins

| Plugin | Description | Version |
|--------|-------------|---------|
| [google-ads](./plugins/google-ads) | Google Ads account management | 2.0.0 |
| [meta-ads](./plugins/meta-ads) | Meta Ads account management | 1.0.0 |

## Getting Started

Visit [claudeppc.ai](https://claudeppc.ai) for installation instructions, documentation, and FAQ.
